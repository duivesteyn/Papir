Papir — Paper P icon

Folded ivory paper monogram on forest green, with transparent outer corners.

Files
- Papir-master-1254.png: original generated artwork, 1254 × 1254 pixels.
- Papir-1024.png through Papir-16.png: exports from the same master.
- Papir.icns: multi-resolution macOS icon container.
- AppIcon.appiconset: macOS asset catalog set (1x and 2x).
- Papir.iconset: source PNGs for iconutil.

Use
Add AppIcon.appiconset to your Xcode asset catalog and select AppIcon as the app icon set. Alternatively use Papir.icns for an app bundle that takes an ICNS resource.

The color app icon is intended for Finder, Dock, and app identity. For a menu bar status item, use a simplified monochrome template glyph so it adapts to light and dark appearance.
