# Test fixtures

`signer-test-key.pem` is a throwaway 2048-bit RSA key generated by
`make-fixtures.py`. It exists only so the Kotlin signing test can be regenerated
deterministically — it has never been registered with Amazon and is not a
credential for anything.

`make-fixtures.py` writes `Fixtures.kt`, which pins the digest the Python
signer produces for this key. `SignerTest` then checks the Android port produces
the same bytes. Regenerating the fixture rewrites the key file only if it is
missing.
